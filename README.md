# Joanna Kleemann – UGC Portfolio

Statische One-Page-Seite (HTML/CSS/JS, keine Abhängigkeiten außer Google Fonts).

- `index.html` – die Seite
- `img/` – Fotos, Logos, Analytics-Screenshots
- `video/` – Beispiel-Videos (540×960, H.264)

Veröffentlicht über GitHub Pages. Suchmaschinen sind per `robots.txt` und `noindex` ausgesperrt – die Seite ist nur über den Link erreichbar.
