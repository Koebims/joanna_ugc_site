Hosting

Diese Website wird über GitHub Pages bereitgestellt. Anbieter ist die GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA.

Beim Aufruf der Website verarbeitet GitHub automatisch technische Daten, die dein Browser übermittelt, insbesondere deine IP-Adresse, Datum und Uhrzeit des Zugriffs, die aufgerufene Seite sowie Browser- und Betriebssysteminformationen (Server-Logfiles). Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO; das berechtigte Interesse liegt in einer sicheren und stabilen Bereitstellung der Website. Dabei können Daten in die USA übertragen werden. GitHub ist nach eigenen Angaben unter dem EU-US Data Privacy Framework zertifiziert. Weitere Informationen: Datenschutzerklärung von GitHub.
